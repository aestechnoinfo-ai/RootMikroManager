# Code couleur des logs RootMikroManager

La même classification est utilisée sur l'accueil et sur l'écran complet des logs.

- Vert : succès, connexion, démarrage, activation, création.
- Orange : avertissement, retry, expiration, valeur haute/basse.
- Rouge : erreur, échec, refus, timeout, déconnexion, perte, panne.
- Rouge critique : fatal, panic, critical, emergency.

Les logs informatifs utilisent aussi une couleur/icône par famille :
Hotspot, PPP/PPPoE, Firewall, Interface, Wi-Fi, DHCP, System,
Script/Scheduler, Account et Routing.

La gravité garde toujours la priorité sur la famille.
