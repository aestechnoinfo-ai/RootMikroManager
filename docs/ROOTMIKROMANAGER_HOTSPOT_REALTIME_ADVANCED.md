# Hotspot temps réel avancé

## Sessions actives
- filtre par serveur ;
- recherche ;
- user, server, IP, MAC, uptime, RX/TX, time left et login-by ;
- auto-rafraîchissement avec la fréquence globale définie dans Paramètres ;
- toucher une session ouvre l'utilisateur Hotspot correspondant ;
- déconnexion séparée.

## Hosts
Filtres :
- Tous ;
- Authorized ;
- Bypassed.

Badges :
- A = authorized ;
- H = DHCP ;
- D = dynamic ;
- P = bypassed.

Un Host peut être supprimé ou converti en IP Binding.

## Cookies
Recherche et suppression. Les cookies proches de l'expiration sont signalés
visuellement en orange.

## IP Binding
Ajout, modification, activation/désactivation et suppression.
Les types regular, bypassed et blocked restent distincts.
