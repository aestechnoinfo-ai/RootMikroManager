# Rapports avancés RootMikroManager

Cette phase sépare trois usages :

1. Selling Report
   - ventes ;
   - devise ;
   - filtre jour / mois ;
   - filtre profil ;
   - filtre commentaire / batch ;
   - CSV ;
   - impression/PDF ;
   - résumé par profil.

2. User Log
   - date ;
   - heure ;
   - username ;
   - adresse IP ;
   - MAC ;
   - validité ;
   - filtre jour / mois ;
   - recherche ;
   - CSV.

3. Resume Report
   - mois sélectionné ;
   - nombre de vouchers par jour ;
   - revenu par jour ;
   - total mensuel avec la devise globale RootMikroManager.

Les profils Hotspot restent des profils. Les vouchers restent des identifiants
générés. Les enregistrements de rapport restent des données de rapport.
