# Lot Hotspot monitoring / Live Report

## Live Report
Écran dédié :
- vouchers et CA du jour ;
- semaine courante ;
- mois courant ;
- historique total ;
- CA du mois ventilé par profil ;
- devise globale RootMikroManager.

## Hotspot Active
Monitoring dédié avec :
- recherche ;
- filtre serveur ;
- actualisation automatique configurable 2–300 s ;
- pause automatique lorsque l'application quitte le premier plan ;
- trafic par session ;
- ouverture du compte Hotspot associé ;
- déconnexion avec confirmation configurable.

## Hosts
Le détail d'un host affiche les propriétés RouterOS disponibles sans imposer
une liste fixe susceptible de varier selon la version RouterOS.

## IP Binding
Éditeur dédié :
MAC, address, to-address, server, type regular/bypassed/blocked,
commentaire et état activé.

## Export utilisateurs
Export CSV local sans `file_picker`, dans le dossier documents de l'application.
