# Wi-Fi / Wireless avancé

RootMikroManager détecte les deux familles RouterOS :
- `/interface/wifi` pour le nouveau package WiFi ;
- `/interface/wireless` pour le package historique.

Le lot ajoute :
- inventaire radio unifié ;
- résumé par backend ;
- registration table ;
- déconnexion d'un client enregistré ;
- profils sécurité en lecture protégée ;
- scan Wi-Fi depuis une interface radio ;
- détails complets d'interface.

Les champs contenant des clés, passphrases ou mots de passe ne sont pas
affichés dans l'écran des profils de sécurité.
